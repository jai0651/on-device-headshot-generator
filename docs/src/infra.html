The rule: GPU work on a pod, everything else on the Mac

The Mac (an M4 with 16 GB) writes and smoke-tests every script, prepares data, and does all the measuring. A rented RunPod GPU does only what genuinely needs one: generating images and training. The pod exists for exactly as long as that work runs.

Choosing a GPU

These workloads are small: SD 1.5 inference fits in 16 GB, LoRA training in about 6 GB per run. So the choice is price and availability, never speed. You approve a list, cheapest first, and the create script tries only that list. Two things learned: RunPod's stock API often lists cheap GPUs as unavailable when a create attempt succeeds anyway (a failed attempt is free), and spot pods are no longer offered at all.
